# Multi-Model-AI-For-Intent-Based-Human-Cobot-Collab
COMP 499 Capstone Project

Pick and Place Operations with the use of Universal Robots (UR):
Python Script parses voice command and translates to STT through natural language processing (spaCy) and writes to register that are linked to a URScipt program to then execute commands

Hardware Used:
UR7e, Collaborative Robot Arm made by UR
External Microphone (Fifine)

Software Used (Ran on Intel Chip on Macbook Pro):
Python
spaCy (NLP)
